## CAN Migration (2026-10-09)

X2Cscope transport moved from TCP/IP over 10BASE-T1S to CAN1. All T1S, lwIP, TC6 and MQTT code was removed.

- **Transport**: CAN1, classic CAN 2.0, 500 kbit/s, standard 11-bit IDs, no BRS
- **IDs**: Device -> PC `0x100` (sent via TXQ); PC -> Device `0x110` (hardware filter 0 -> FIFO1 custom name `X2CSCOPE_RX`, 8 deep)
- **Single source of truth for IDs**: `X2CSCOPE_CAN_TX_ID` / `X2CSCOPE_CAN_RX_ID` in `X2CscopeComm.c`. `can_rx_filter_config()` (called from `X2CscopeComm_PostInit()`) reprograms filter 0 (exact 11-bit SID match, standard only) and routes it to `X2CSCOPE_RX`. MCC filter 0 is kept enabled (ID 0x110 -> FIFO1) but its ID is overwritten at init. Filter 0 is reserved for X2Cscope.
- **Compile-time checks**: `#error` if `X2CSCOPE_RX` is not defined by MCC (`can1.h`), and if either ID > 0x7FF
- **Pins**: CAN1TX = RC11 (RP44), CAN1RX = RC10 (RP43), PPS in `pins.c`
- **Clock**: CAN needs a stable clock -> External Clock from the 8 MHz MEMS oscillator (Y1) on the DIM, on OSCI. PLL1 source = Primary Oscillator/External Clock (PLLPRE 1, PLLFBDIV 200, VCO 1600 MHz, out 200 MHz). CLK10 = 20 MHz FCAN.
- **Hardware**: ATA6563 click (MIKROE-2334) on an Xplained Pro extension in XPRO1. The click needs 3.3 V and 5 V; XPRO1 only has 3.3 V, so 5 V is jumpered from header J5 (5V) to 5V_EXT on the Xplained Pro extension. PC side: PCAN-USB. Board photo: `assets/board_motor_can.jpg`.
- **Implementation**: `src/X2Cscope/X2CscopeComm.c`, based on X2Cscope library `interface/examples/can`
  - `sendSerial()` packs bytes into 8-byte CAN frames; `flushSerial()` sends the remainder at the end of each LNet frame
  - `X2CscopeComm_Communicate()` reads `X2CSCOPE_RX` into a 128-byte ring buffer (no software ID check, hardware filter does it), then calls `X2Cscope_Communicate()`; it is called from the main loop instead of `X2Cscope_Communicate()`
  - `X2Cscope_Update()` still called in `ADC2_ChannelCallback` (20 kHz)
- **Status**: tested and working on hardware (2026-10-09)
- **Host**: pyX2Cscope >= 0.7.0, CAN interface, USB-CAN adapter (e.g. PCAN-USB), bitrate 500k, TX ID `0x110`, RX ID `0x100`, ELF `out/AK512_FOC_CAN/default.elf`
- **Removed**: `src/T1S`, `src/MQTT`, `src/hal/T1S`, `src/hal/MQTT`, `libs/liblwip`, `libs/libtc6`, `mqtt_app`, `src/userparms.h`. `hal.h` no longer has `MIKROE_T1S` / `MQTT_ENABLED` / `BOARD_LABEL` / `get_mcu_uid`. SPI1 and I2C3 are no longer in MCC.
- **Speed reference**: always from the potentiometer (remote control via `is_remote_control()` removed)
- **MCC folder / project**: `dsPIC33AK512MC510_MCLV48V300W_CAN`, project configuration `AK512_FOC_CAN`

### 3. Key Design Decisions

- **ADC2_ChannelCallback** stays in `main.c` for visibility — calls `MC_APP_ISR()` + `X2Cscope_Update()`
- **`mcInitDone` guard** prevents ISR from executing FOC before initialization completes
- **Direction reversal**: SW2 stops motor (FOC decelerates to zero via `MCAPP_STOPPING` state), then auto-restarts in new direction
- **X2Cscope**: originally kept the T1S TCP/IP implementation (not the old UART one from LAB4_FOC); now replaced by CAN1 transport (see CAN Migration above)
- **MCC generated files**: NEVER modified directly — if changes needed, user regenerates via MCC

### 4. Overcurrent Protection (CMP3 + PWM Fault PCI)

Implemented in `MC_HAL_OverCurrentProtectionInit()` inside `mc_hal.c`:

- **CMP3/DAC3**: Monitors bus current via OPA3 output on **CMP3A (RA5)** — `INPSEL = 0`
- **DAC reference**: `CMP_REF_DCBUS_FAULT` ≈ 2979 counts (10A threshold)
- **Comparator polarity**: `CMPPOL = 0` (non-inverted: output HIGH when overcurrent)
- **PWM Fault PCI**: `PGxF1PCI1 = 0x03001000` (TERM=1 cycle-by-cycle, ACP=3 latched, PPS=0)
- **PCI source**: `PGxF1PCI2 = 0x40000000` (bit 30 = CMP3 output)
- **Generators disabled** before writing PCI registers, then re-enabled
- **DAC calibration**: reads Flash at 0x7F20E0 for POSINLADJ/NEGINLADJ/DNLADJ
- **Hysteresis**: 45 mV (HYSSEL=3)

**Status**: INPSEL was corrected from 3 (CMP3D) to 0 (CMP3A) at end of session. Needs testing to confirm cycle-by-cycle clipping works.

### 7. Key Register Values Reference

| Register | Value | Meaning |
|----------|-------|---------|
| PGxF1PCI1 | 0x03001000 | TERM=1 (cycle-by-cycle), ACP=3 (latched), PPS=0 |
| PGxF1PCI2 | 0x40000000 | Source = CMP3 output (bit 30) |
| DAC3CMP | INPSEL=0, INNSEL=0, CMPPOL=0, HYSSEL=3 | CMP3A input, DACx ref, non-inverted, 45mV hysteresis |
| CMP_REF_DCBUS_FAULT | ~2979 | (10A * 2048 / 22A) + 2048 |
